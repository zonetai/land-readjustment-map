# 災害與環境風險（risk）圖資包：來源與查證紀錄

查證日期：2026-11-25（臺北時間 11-25 深夜）。所有對外服務都是從 `https://zonetai.github.io` 來源的瀏覽器分頁用 `fetch()` 實測，測得到就等於上線後網頁拿得到。

- 對估價：點一個位置就得到淹水、液化、斷層、地質敏感區、土石流、水利管制區的「有／沒有、等級、距離」，以及可直接貼進報告「災害潛勢」段落的句子。

#### 已知限制
- 像素判級是「看圖說話」：精度受圖磚解析度限制（液化約 2 公尺一格；地質敏感區、土石流、海嘯約 4～17 公尺一格），色塊交界處可能判到隔壁一級。detail 都有寫。
- 「鄰近」只在同一張圖磚內找；已盡量挑讓點位離邊緣夠遠的縮放層級，極少數位置（三個層級都貼邊）可能漏報鄰近。
- `GeoSensitive` 的地質遺跡類顏色沒有實地樣本，遇到紅藍以外的顏色只回「類別請開圖層確認」。
- 大安站、板橋站兩個測試點在中級液化圖上都讀到紅色（高潛勢）。配色對應已用大同區（整片紅）與大安 z14 圖磚（黃為主）交叉確認，但**沒有拿官方液化查詢系統逐點對過**，上線前請用 https://www.liquid.net.tw/ 抽兩三個地址核對一次。
- 土石流／大規模崩塌的村里清單是即時抓農村水保署網站的 JSON（非正式 API），該站改版就會失效，失效時本項只剩圖面判斷。
- 核電廠座標為廠區中心概略位置（村里核對過，未與官方座標逐一比對），距離誤差數百公尺內。
- 斷層距離門檻 150 公尺、建築禁限建 30～100 公尺是通則性描述，個案以公告之地質敏感區圖及地方政府建管規定為準。

## 三、整合注意
- pack.js 可在 node 載入（用全域 `GIS`）；像素判級的五個項目在 node 會拋「此項目需在瀏覽器執行」，屬預期。
- 圖層 id 一律以 `risk_` 開頭，沒有與 `catalog.js` 既有 id 相同者。平台既有的液化初級、海嘯、土石流、順向坡、斷層 WMS、淹水 650mm 圖層都沒有重複登錄。
- `active_faults` 設為 `showAsLayer: true`，與既有的斷層 WMS 圖層內容重疊（WMS 是地質圖上所有斷層，這份只有活動斷層且可點出名稱），介面上可並存。
- `risk_water_zone` 的自來水水質水量保護區、海岸防護區可能與「規劃開發」包重疊，整合時請看要留哪一邊。
- `risk_flood` 與 `risk_water_zone` 共用同一個 identify 請求（靠 `ctx.arcgisIdentify` 的快取鍵相同），兩個項目要一起跑才省請求。
