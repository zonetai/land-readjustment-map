# 體檢地圖

給一般民眾查「我家這裡有什麼狀況」的公開地圖：點一個位置，就能看到災害風險、生活機能、地價與人口、都市計畫與開發、市地重劃與區段徵收等項目。純靜態網頁，免登入。

網址：https://zonetai.github.io/land-readjustment-map/ （自動導向 `platform/`）

## 網站結構

| 路徑 | 內容 |

| `platform/` | **體檢地圖（整合版主入口）**：地點體檢、主題圖資、歷年航照比對、政府公開圖層；說明見 `platform/README.md` |
| `platform/packs/` | 圖資包：`living` 生活機能、`risk` 災害風險、`economy` 地價與人口、`planning` 規劃開發、`landdev` 市地重劃與區段徵收 |

## 重要說明

1. **平均分回比例為換算值**：本站顯示之「平均分回比例」＝100%－總負擔比率，係由公布之負擔比率推算，並非主管機關公布之數字；個別土地所有權人實際分配比例依其土地位置、地價及分配結果而異。
2. 辦理中重劃區之負擔比率為重劃計畫書核定之預估值，最終以土地分配結果公告為準。
3. PDF 數字以文字層抽取，每筆核對「公設負擔＋費用負擔＝總負擔」（誤差 0.1% 以內）。桃園市 32 份文件中有 19 份為掃描檔、1 份數值欄空白，無法抽取，未填數字。
4. 新北市重劃範圍圖層未涵蓋全部重劃區（部分早期自辦重劃區無範圍），此類重劃區只列於屬性總表。
5. 新店大坪林市地重劃區之總負擔比率 77.92% 明顯高於其他區；開放資料與新北市成果統計表 PDF 同為此值，屬官方原值，使用前宜再查證。
6. 臺中市開放資料部分年度之負擔值漏小數點（例如 3084 應為 30.84），本站已改以除以 100 計，並於「核對註記」標示原始值。
7. 臺南市「佳里國小」「賢北二」兩區之公設＋費用負擔與平均負擔不符（逾 0.1%），照原值列出並標示，使用前宜查證。
8. 高雄市負擔比率另取自地政局各重劃區介紹頁；部分頁面未載平均負擔，以公設＋費用加總計並註明。第19、36、61期與第74期自辦之介紹頁數字彼此不符（例如第36期載平均 0.89%，公設＋費用為 40.89%），照原值列出並標示；早期公辦部分頁面註明「資料佚失」，多數早期自辦頁面無內容，仍無負擔比率。
9. 桃園市府、臺南市府圖資伺服器：桃園連線失敗；臺南 ldmap、up 伺服器之圖層均需授權（Token），未予取得。新北地政 WebGIS 除既有圖層外無其他重劃範圍圖層。
